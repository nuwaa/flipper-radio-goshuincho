# Phase D theme previews

Every base PNG and PBM is the exact 128×64, one-bit bitmap produced by the C renderer. Files ending in `_8x.png` use nearest-neighbor scaling to 1024×512.

`themes_comparison_8x.png` is arranged in row-major order:

1. Demo — square seal and geometric center crest
2. 315 MHz — keyhole and concentric ripples
3. 426 MHz — control panels and antenna tower
4. 429 MHz — gear, hexagon, and industrial strokes
5. 433 MHz — wheel and flowing tracks
6. 920 MHz — connected constellation nodes
7. 5 Bands — one integrated five-crest composition

Regenerate all files with `tests/generate_theme_previews.sh`.

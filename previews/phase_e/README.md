# Phase E collectible previews

Base PNG/PBM files are exact 128×64 one-bit renderings. `_8x.png` files use nearest-neighbor enlargement.

- `seasons_comparison_8x.png`: Spring, Summer, Autumn, Winter in row-major order.
- `rarities_comparison_8x.png`: Travel, Quiet, Spark, Storm, Five Harmony in row-major order.

Regenerate them with `tests/generate_collectible_previews.sh`.
